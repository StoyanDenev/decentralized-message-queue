Status: **PENDING-COUNSEL** (`docs/proofs/DECISION-LOG.md` 2026-07-25, licensing v3.1). This

text is for counsel to draft. **Nothing here grants any rights.**

The core (everything outside `dapps/`) is Apache-2.0 and free for everyone — there is no paid
core license. The Licensor operates reference DApp instances on the network free of charge for
end users.

## What is sold

1. **DApp production grants (the royalty)** — production deployment/operation of any reference
   DApp (`dapps/`, D.1–D.9) **by or for a commercial entity, or by or for a government /
   public-sector body**. Free without a grant: development, evaluation, testing, CI, and
   noncommercial production by natural persons and noncommercial organizations (BUSL
   Additional Use Grant). Pricing axes for counsel + owner to fix: per deployment / per node /
   per seat / per annum.
2. **"Determ Certified" trademark license** — certification program for operators and
   integrators; independent of the code licenses (a fork keeps the code, not the name).
3. **Compliance-evidence + security-update subscription** — audit reports, FIPS/NIS2 evidence
   packages, patch SLA; independent of the code licenses.

Every commercial grant carries sanctions / end-use screening clauses (counsel item).
